# 🚒 Herói das Chamas

Jogo em HTML da casa em chamas com o bombeiro sendo o Herói.

## 🎯 Objetivo

Você é um bravo bombeiro e sua missão é encontrar o cômodo da casa onde ainda há uma pessoa presa nas chamas.

## 🕹️ Como jogar

1. Abra o arquivo `index.html` no navegador.
2. Você começa na **rua**, em frente à casa em chamas.
3. Clique nas opções para navegar entre os cômodos.
4. Encontre o **Quarto 2** para resgatar a pessoa e concluir a missão.

## 🗺️ Mapa da casa

- **Rua** → Sala ou Quarto 2
- **Sala** → Corredor, Quarto 2 ou Rua
- **Corredor** → Quarto 1, Banheiro, Cozinha ou Sala
- **Quarto 1** → Corredor
- **Banheiro** → Corredor
- **Cozinha** → Corredor
- **Quarto 2** → ✅ Missão cumprida!
